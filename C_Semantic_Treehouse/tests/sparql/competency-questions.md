# SPARQL Competency Questions

These competency questions test whether the semantic model can answer practical data space governance questions from the v0.3 ontology and example data.

| ID | Question | Governance purpose |
|---|---|---|
| CQ1 | What is the dataset identifier? | Confirms catalogue identity can be retrieved. |
| CQ2 | Who is the provider? | Confirms provider metadata is explicit for onboarding. |
| CQ3 | What endpoint URL exposes the data product? | Confirms connector/offering integration metadata is queryable. |
| CQ4 | What format and frequency does the data product use? | Confirms basic offering constraints are queryable. |
| CQ5 | What unit is required by the model? | Confirms unit constraints can be inspected. |
| CQ6 | What spatial and temporal coverage does the metadata declare? | Confirms coverage metadata is queryable. |
| CQ7 | Which model version does the metadata conform to? | Confirms version binding through `dct:conformsTo`. |
| CQ8 | What fields define an Energy Reading Record? | Confirms the payload model can be discovered from ontology terms. |
