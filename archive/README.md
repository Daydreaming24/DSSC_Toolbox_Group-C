# v0 历史归档

本目录中的内容来自 v0 基线（即原始仓库）或旧工作区，均为历史只读材料。它们保留原始字节用于审计和理解，但不再维护，也不代表 v0.4 当前状态。

- `v0_docs/`：旧版解释文档及原仓库内嵌文档。
- `v0_phase_summaries/`：Phase 0–8 总结与旧最终总结。
- `v0_validation_reports/`：旧环境生成的验证报告。
- `v0_evidence/`：旧 Semantic Treehouse 部署证据。
- `v0_quality/`：旧质量评估。
- `v0_ci/`、`v0_tooling/`：已停用的 CI、Make、Docker 和 Windows 入口。

需要修正历史材料时，请在 `docs/v0.4/` 记录勘误，不要回写归档文件。

少量含个人绝对路径的历史文件未进入公开工作树；排除项、原哈希和恢复来源见 `docs/provenance/privacy-exclusions.md`。
